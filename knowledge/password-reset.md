# Password Reset

Before resetting a password, verify the user's identity according to the
organisation's identity verification procedure.

Never ask the user to send their existing password by email or chat.

After identity verification, reset the password using the approved identity
management system.

Require the user to change temporary credentials at the next sign-in where
supported.

If the account is locked, check whether repeated authentication attempts or
stored credentials on another device are causing the lockout.

For repeated lockouts, investigate saved credentials on mobile devices,
email clients, scheduled tasks, or mapped network resources.

Escalate suspicious authentication activity according to the organisation's
security incident procedure.
