# Wi-Fi Troubleshooting

If a user cannot connect to Wi-Fi, first determine whether the problem affects
one device or multiple devices.

For a single device, confirm that Wi-Fi is enabled and airplane mode is
disabled.

Ask the user to forget the wireless network and reconnect using the correct
credentials.

Check whether the device receives a valid IP address, default gateway, and DNS
servers.

If the device connects to Wi-Fi but cannot access the internet, test the
default gateway and then an external IP address.

If multiple users are affected, investigate the wireless access point,
DHCP service, switching infrastructure, and upstream internet connection.

Escalate widespread wireless outages to the network team.
